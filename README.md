# Fleet Logistics System (Система логістики та управління автопарком)

Програмний комплекс призначений для автоматизації процесів обліку транспортних засобів, контролю вантажопідйомності та розрахунку вартості доставки комерційних вантажів. Проєкт розроблено в межах лабораторної роботи №7 з дисципліни "Програмування, алгоритмізація та основи промпт-інжинірингу".

## 🚀 Основний функціонал

* **Управління автопарком:** Роздільне додавання та облік вантажівок (`Truck`) та фургонів (`Van`) з використанням перелічуваних типів палива (`FuelType`).
* **Поліморфна ієрархія ТЗ:** Розрахунок кінцевої вартості доставки за допомогою перевизначеного методу `calculate_delivery_cost(distance)`.
* **Валідація вантажопідйомності:** Стійка бізнес-перевірка лімітів вантажу. Система блокує спроби завантажити транспортний засіб понад його встановлений максимум.
* **Персистентність даних:** Імітація збереження поточного стану системи у бінарний файл за допомогою бібліотеки `pickle` та генерація фінансової звітності у формат `csv`.
* **Інтерактивний CLI-інтерфейс:** Зручне та інформативне текстове меню на базі сучасного оператора `match/case` зі 100% захистом від падіння програми при некоректному введенні (Fault Tolerance).
